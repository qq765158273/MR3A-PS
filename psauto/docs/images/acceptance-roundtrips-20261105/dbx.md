# DBX 只读验收查询

连接 `ps-dev / HRDEV`。数据库只在 MCP 操作结束后验收，不参与创建或 Build 写入。工具完整返回分别保存于 [Record3](dbx_record3.json) 和 [同实例 Field→Record4](dbx_continuity.json)。

```sql
SELECT RECNAME, RECTYPE FROM PSRECDEFN
WHERE RECNAME IN ('GM_RPC_REC','GM_RPC_REC2','GM_RPC_REC3') ORDER BY RECNAME;
SELECT FIELDNAME, FIELDNUM, USEEDIT FROM PSRECFIELD
WHERE RECNAME='GM_RPC_REC3' ORDER BY FIELDNUM;
SELECT TABLE_NAME,TABLESPACE_NAME FROM USER_TABLES WHERE TABLE_NAME='PS_GM_RPC_REC3';
SELECT INDEX_NAME,STATUS,UNIQUENESS FROM USER_INDEXES
WHERE TABLE_NAME='PS_GM_RPC_REC3' ORDER BY INDEX_NAME;
SELECT COUNT(*) AS ROW_COUNT FROM PS_GM_RPC_REC3;

SELECT FIELDNAME,FIELDTYPE,LENGTH FROM PSDBFIELD WHERE FIELDNAME='GM_RPC_F1';
SELECT FIELDNAME,LABEL_ID,LONGNAME,SHORTNAME FROM PSDBFLDLABL WHERE FIELDNAME='GM_RPC_F1';
SELECT FIELDNAME,FIELDNUM,USEEDIT FROM PSRECFIELD
WHERE RECNAME='GM_RPC_REC4' ORDER BY FIELDNUM;
SELECT TABLE_NAME,TABLESPACE_NAME FROM USER_TABLES WHERE TABLE_NAME='PS_GM_RPC_REC4';
SELECT INDEX_NAME,STATUS,UNIQUENESS FROM USER_INDEXES
WHERE TABLE_NAME='PS_GM_RPC_REC4' ORDER BY INDEX_NAME;
SELECT COUNT(*) AS ROW_COUNT FROM PS_GM_RPC_REC4;
```

两张最终表字段顺序与请求一致，前三字段 USEEDIT=8390689，后两字段=8388656；表空间 HRAPP，均有 1 个 UNIQUE 和 2 个 NONUNIQUE 索引、状态均 VALID，表内 0 行。新字段 GM_RPC_F1 为类型 0、长度 11，标签 GMRPC，长名 GM RPC Field、短名 GM RPC。首次未保存的 GM_RPC_REC 无定义行；第二次已保存的 GM_RPC_REC2 有定义，不能将其原 MCP 的 partial 状态改计完整成功。

# DBX 只读验收

2026-11-05，主控使用 DBX 的 `ps-dev / HRDEV` 连接，在 MCP 完成后执行以下只读 SQL；未通过数据库创建或修改对象。

```sql
SELECT RECNAME, RECTYPE FROM PSRECDEFN WHERE RECNAME='GM_EXP_REC';
SELECT FIELDNAME, FIELDNUM, USEEDIT FROM PSRECFIELD WHERE RECNAME='GM_EXP_REC' ORDER BY FIELDNUM;
SELECT TABLE_NAME, TABLESPACE_NAME FROM USER_TABLES WHERE TABLE_NAME='PS_GM_EXP_REC';
SELECT COUNT(*) AS ROW_COUNT FROM PS_GM_EXP_REC;
```

DBX 返回定义 `GM_EXP_REC / RECTYPE=0`，物理表 `PS_GM_EXP_REC / HRAPP`，表内 0 行。

| FIELDNUM | FIELDNAME | USEEDIT |
| --- | --- | --- |
| 1 | GM_OPT_EMPLID | 8390689 |
| 2 | EMPLID | 8390689 |
| 3 | EMPL_RCD | 8390689 |
| 4 | EFFDT | 8388656 |
| 5 | EFFSEQ | 8388656 |

字段顺序和 USEEDIT 与已验收的 GM_OPT_REC 相同：前三字段 Key / Listbox / Search Key；后两字段 Alternate Search Key / Listbox。

```sql
SELECT INDEX_NAME, STATUS, UNIQUENESS FROM USER_INDEXES
WHERE TABLE_NAME='PS_GM_EXP_REC' ORDER BY INDEX_NAME;
SELECT COLUMN_NAME, DATA_TYPE, DATA_LENGTH, DATA_PRECISION FROM USER_TAB_COLUMNS
WHERE TABLE_NAME='PS_GM_EXP_REC' ORDER BY COLUMN_ID;
```

返回 3 个 VALID 索引：`PS_GM_EXP_REC` 为 UNIQUE，`PS0GM_EXP_REC`、`PS1GM_EXP_REC` 为 NONUNIQUE。物理字段类型依次 VARCHAR2、VARCHAR2、NUMBER、DATE、NUMBER；前两个 VARCHAR2 的 DATA_LENGTH 为 44 字节，不能将其误当作 44 字符。第二批 DBX 工具的完整结构化返回保存在 [dbx_indexes.json](dbx_indexes.json)。
